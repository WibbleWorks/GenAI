# 🤖 Generative AI & Machine Learning Mastery Course

**Complete AI/ML training course from 101 fundamentals to PhD-level expertise with practical interactive lessons, animations, and cloud/local environment support.**

## 📚 Course Overview

This comprehensive course takes you from AI/ML basics to advanced research topics, with a special focus on the intersection between Generative AI and Quantum Computing.

### 🎯 Learning Path

**Level 1: AI & ML 101 (Beginner)**
- Introduction to Artificial Intelligence
- Machine Learning Fundamentals  
- Neural Networks Introduction

**Level 2: Core Machine Learning (Intermediate)**
- Hands-on scikit-learn
- Classic ML algorithms with practical examples

**Level 3: Deep Learning & Neural Networks (Advanced)**
- Practical TensorFlow
- Advanced PyTorch applications

**Level 4: Generative AI & LLMs (Expert)**
- HuggingFace Transformers
- LangChain applications
- **⚛️ Quantum-AI Intersection** - NEW!

**Level 5: AI Research Frontiers (PhD)**
- Building AI Agents
- Multi-agent systems
